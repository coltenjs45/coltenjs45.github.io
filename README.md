# Colten Stevens: Senior Portfolio

Static site for CprE/CybE/EE 494. Plain HTML and CSS, no build step.

## Publish on GitHub Pages

1. On GitHub, create a new **public** repository named exactly `coltenjs45.github.io`.
2. Upload every file in this folder (keep the `assets` folder) using **Add file → Upload files**, then commit.
3. Go to **Settings → Pages**. Under "Build and deployment", set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. After a minute or two the site is live at `https://coltenjs45.github.io`.

To change something later, edit the `.html` file on GitHub (pencil icon) and commit. The site updates on its own.
